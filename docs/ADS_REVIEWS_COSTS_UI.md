# 광고 UI/UX 레이아웃 스펙 — 리뷰분석 · 광고비관리

신규 64 (`yuksa-64` / `https://y64.xyz`)에서 SKADI `64/ads` 원본과 **동등한 밀도·정보 구조**로 맞추기 위한 화면 가이드다.

| 화면 | 원본 | Next 라우트 |
|------|------|-------------|
| 리뷰분석 | `64/ads/index.php` | `/ads/reviews` |
| 광고비관리 | `64/ads/ad_cost.php` | `/ads/costs` |

공통: 상단 `AdsSubnav`(리뷰 / 광고비 / 통계), **지점 선택**, **이전달·다음달**.  
권한: OWNER / MANAGER / SUPERADMIN. 데이터는 `branchId` 스코프.

---

## 0. 공통 레이아웃

```
┌─────────────────────────────────────────────────────────────┐
│ PageHeader: 제목 + 설명                                      │
│ actions: [지점 select] [◀ 이전달] YYYY년 M월 [다음달 ▶] …   │
├─────────────────────────────────────────────────────────────┤
│ AdsSubnav:  리뷰분석 | 광고비 | 광고통계                      │
├─────────────────────────────────────────────────────────────┤
│ (필터 / 요약 카드 / 본문 테이블·모달)                         │
└─────────────────────────────────────────────────────────────┘
```

- 페이지 폭: 광고 구간 `max-w-[1400px]` (리뷰 매트릭스용). 그 외 앱은 `max-w-6xl`.
- 배경·카드: 기존 잉잉 디자인 토큰(`paper` / `card` / `ink` / `line` / `gold`) 유지.
- 모바일: 헤더·필터는 세로 스택, 테이블은 가로 스크롤.

## 1. 리뷰분석 `/ads/reviews`

### 1.1 정보 구조 (위에서 아래)

1. **헤더 카드**
   - 좌: 아이콘(별) + 제목 `리뷰분석`
   - 우: 지점 + 월 네비
2. **필터 바** (헤더 바로 아래, 연한 배경)
   - 플랫폼 select (전체 / 배민 / 쿠팡…)
   - 기간 `startDate ~ endDate` (선택 — 월 네비와 병행 시, 기간이 있으면 일 컬럼을 기간으로 클립)
   - 점포유형: 전체 / 자사 / 경쟁사
   - 초기화 버튼
3. **액션 바**
   - 좌(주 CTA): `리뷰수 입력` — 크게(강조색, 예: purple/gold)
   - 우(보조): `점포추가` · `플랫폼추가` — 작은 ghost/soft
4. **월간 요약 카드 4열**
   | 카드 | 내용 |
   |------|------|
   | 등록 점포 | 활성 점포 수 |
   | 자사 점포 | OWN 수 |
   | 자사 월 리뷰 증가 | OWN 점포별 (MAX−MIN) 합 |
   | 자사 평균 증가 | 위 합 / OWN 수 |
5. **플랫폼별 매트릭스 테이블** (플랫폼마다 Panel 1개)
6. 빈 상태: “등록된 점포가 없습니다” + 첫 점포 추가 CTA

### 1.2 매트릭스 테이블 (핵심 UX)

```
┌──────────┬────┬────┬────┬ … ┬────┬────┬────┐
│ 점포     │ 1  │ 2  │ 3  │    │ 31 │증감│평균│
├──────────┼────┼────┼────┼ … ┬────┼────┼────┤
│ 송파 자사│123 │+2  │…   │    │    │ + │ n  │
│ 경쟁A    │…   │    │    │    │    │    │    │
└──────────┴────┴────┴────┴ … ┴────┴────┴────┘
```

필수 규칙:

| 규칙 | 상세 |
|------|------|
| sticky 점포명 | 첫 열 `position: sticky; left: 0`, 가로 스크롤 시에도 고정 |
| 일 컬럼 | 해당 월 1~말일 (또는 기간 필터 구간) |
| 셀 값 | **누적 리뷰수** (당일 스냅샷). 없으면 `-` |
| 전일 대비 | 셀 아래 작은 글씨. `+N` 초록 / `-N` 빨강. 0이면 숨김 |
| 1일 전일 | 전월 마지막 기록(`prevByStore`)과 비교 |
| 주말 강조 | 토: amber 배경, 일: red 배경 (헤더·셀 모두) |
| 자사 행 | 연한 blue 배경. 경쟁사: 기본/회색 |
| 우측 증감 | 월내 `MAX(count) − MIN(count)` (원본 통계와 동일) |
| 우측 평균 | 값이 있는 날의 산술평균 |
| 그룹핑 | **플랫폼별 테이블 분리**. 테이블 타이틀에 플랫폼명·브랜드 컬러 |

정렬: 자사 먼저 → 점포명. (원본 sort_order 있으면 그 우선)

### 1.3 모달

**리뷰수 일괄입력 (주 CTA)**  
- 필드: 날짜(date)  
- 본문: 현재 지점·필터 기준 점포 목록 × 리뷰수 number  
- 빈 칸은 저장 스킵  
- API: `POST /api/ads` `{ action: "bulk_reviews", branchId, reviewDate, rows:[{storeId, reviewCount}] }`  
- UNIQUE(storeId, reviewDate) upsert

**점포 추가/수정**  
- 플랫폼*, 점포명*, 유형(OWN/COMPETITOR), 주소, 비고  
- API: `action: "store"` (+ `id` 있으면 update)

**플랫폼 추가**  
- 이름*, 코드*(영문), 색상  
- API: `action: "platform"`

### 1.4 인터랙션

- 월 변경 / 지점 변경 / 필터 변경 → 즉시 재조회 (`type=reviews`)
- 저장 성공 → 토스트/Message + 매트릭스·요약 새로고침
- 로딩 중 스피너, 실패 시 에러 메시지

### 1.5 적용 체크리스트 (리뷰)

- [ ] 헤더 + 지점 + 월네비
- [ ] 필터(플랫폼·기간·유형·초기화)
- [ ] 주 CTA 리뷰수 입력 + 보조 점포/플랫폼
- [ ] 요약 카드 4종
- [ ] 플랫폼별 sticky 매트릭스
- [ ] 전일대비 / 주말색 / 자사행 강조
- [ ] 증감·평균 열
- [ ] 3종 모달 + bulk upsert

## 2. 광고비관리 `/ads/costs`

### 2.1 정보 구조

1. **헤더**
   - 좌: 아이콘(₩) + `광고비관리`
   - 우: 지점 + 월 네비 + **광고비 입력** (주 CTA, green/ink)
2. **필터 바**
   - 플랫폼 (전체 가능)
   - 점포 — **자사(OWN)만** 옵션
3. **월간 요약 카드 1행 5열** (합계)
   | 광고지출 | 노출 | 클릭 | 주문 | 주문금액 |
4. **효율 카드 1행 5열** (합계 기준 재계산)
   | CTR % | CVR % | CPC | CPA | ROAS % |
5. **일별 광고비 테이블** + tfoot 합계
6. 빈 상태 + “첫 데이터 입력” CTA

### 2.2 지표 공식 (표시·저장 동일)

```
CTR  = clicks / impressions * 100
CVR  = orders / clicks * 100
CPC  = round(adSpend / clicks)
CPA  = round(adSpend / orders)
ROAS = orderAmount / adSpend * 100
```

분모 0이면 0. 소수 2자리(CTR/CVR/ROAS), CPC/CPA 정수.

### 2.3 일별 테이블

컬럼 순서 (원본과 동일):

| 날짜 | 점포 | 플랫폼 | 광고지출 | 노출수 | 클릭수 | 주문수 | 주문금액 | CTR | CVR | CPC | ROAS | 관리 |
|------|------|--------|----------|--------|--------|--------|----------|-----|-----|-----|------|------|

규칙:

- 금액·수치는 **오른쪽 정렬** `tabular-nums`
- 토/일 행 배경: amber / red (원본 `weekend-row` / `sunday-row`)
- 전 지표가 0인 행은 목록에서 **제외** (API `costs`와 동일)
- 관리: `수정` · `삭제`
- **tfoot**: 보이는 행 합계 + 효율 재계산
- 범례 문구: `CTR: 클릭율 | CVR: 전환율 | CPC: 클릭당비용 | CPA: 주문당비용 | ROAS: 광고수익률`

### 2.4 입력/수정 모달

```
┌─ 광고비 입력 ─────────────────────┐
│ 점포(자사)*   [select]             │  ← 신규만
│ 날짜*         [date]               │  ← 신규만
│ 광고비 / 노출 / 클릭 / 주문 / 주문금액 │
│ 메모(notes)                        │
│ 미리보기: CTR CVR CPC CPA ROAS     │  ← 입력 중 실시간
│              [취소] [저장]          │
└────────────────────────────────────┘
```

규칙:

- 점포 선택 시 `platformId`는 점포의 플랫폼으로 자동
- **수정 시** 점포·날짜·플랫폼은 잠금 (원본 `update_ad_cost`와 동일). 수치·메모만 변경
- upsert 키: `UNIQUE(storeId, costDate)`
- API: `POST action:"cost"` / `DELETE ?type=cost&id=`

### 2.5 적용 체크리스트 (광고비)

- [ ] 헤더 + 지점 + 월네비 + 입력 CTA
- [ ] 플랫폼·자사점포 필터
- [ ] 요약 5카드 + 효율 5카드
- [ ] 일별 테이블 + 주말색 + tfoot
- [ ] 모달 실시간 효율 미리보기
- [ ] 수정 시 키 필드 잠금 / 삭제 확인

## 5. 구현 우선순위 (UI 맞출 때)

1. 리뷰: sticky 매트릭스 + 전일대비 + 주말색 + 요약 4카드 + 리뷰수 입력 CTA 크기
2. 광고비: 요약·효율 카드 2단 + 테이블 tfoot + 주말 행색 + 모달 실시간 미리보기
3. 필터 바를 헤더 카드 안으로 넣어 원본처럼 “한 덩어리”로 묶기
4. 기간 필터(리뷰)가 아직 없으면 추가 후 일 컬럼 클립

이 문서를 기준으로 `/ads/reviews`, `/ads/costs`를 조정하면 신규 64에서 원본 UX를 재현할 수 있다.
